# Kleptic Tools

Collection of open-source infrastructure, Kubernetes, gateway, proxy, and observability toolkits.

## Subfolder Index

### API Gateway

- [Kong](kong): Go-based Kong Gateway demo that covers service/route/plugin creation, health checks, and rate-limiting tests.

### Reverse Proxy and Service Mesh

- [Envoy](envoy): Envoy proxy setup and traffic handling examples, including load balancing concepts and service-proxy usage.
- [Traefik](Traefik): Traefik setup guide with Docker/Kubernetes examples, TLS notes, and practical reverse proxy configurations.
- [Istio](istio): Istio service mesh setup with traffic management examples, observability references, and security policy guidance.

### Kubernetes and GitOps

- [Argo](argo): Argo CD GitOps manifests and runbooks, including app-of-apps, ApplicationSet patterns, RBAC, and bootstrap flows.
- [Knative](knative): Knative Serving and Eventing quick start with setup scripts, hands-on manifests, and real scenario flow diagrams.
- [K9s](K9s): Terminal UI workflow for Kubernetes operations with shortcut references and setup guidance.

### Packaging and Deployment

- [Helm](helm): Reusable Helm chart for Kubernetes workloads with configurable values and standard templates.

### Observability and Logging

- [Loki](Loki): Loki logging stack setup guide with configuration examples and Grafana integration pointers.

### Security Scanning

- [trivvy](trivvy): Trivy security scanning toolkit for containers, filesystems, IaC, secrets, and SBOM workflows.
